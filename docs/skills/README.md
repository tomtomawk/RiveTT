# Variantes de skills non installées

Ce dossier conserve les variantes autonomes LITE et UNIFIED destinées aux échanges
manuels et aux essais. Elles ne font pas partie du contenu de l'installateur et
peuvent contenir des descriptions historiques : vérifier leurs signatures et
conventions avant de les utiliser avec une nouvelle version.

Le skill livré et ses références restent dans src/resources/documentation/.
Ce dossier de ressources contient uniquement le guide utilisateur, la configuration
des clients, SKILL.md, ses métadonnées et ses références opérateur. Il est copié
intégralement par le build global, puis installé sous %LOCALAPPDATA%\RiveTT\documentation.
Les recettes et suivis de corrections restent dans docs/.
